Coordinator

טוען לפני שאר הרכיבים ומונע התנגשויות — כל ווידג'ט מקבל מיקום אוטומטי ללא חפיפה. אין ממשק, אין הגדרות. רק מדביקים לפני.

מתי צריך

אם אתם משתמשים ביותר מווידג'ט אחד מ-scriptable.dev על אותו עמוד (למשל accessibility + chat), הוסיפו את ה-coordinator לפניהם — והוא ידאג שלא יחפפו אחד לשני.

אם יש לכם ווידג'ט אחד בלבד — אין צורך ב-coordinator.

התקנה

<!-- coordinator חייב להיות ראשון -->
<script src="https://scriptable.dev/coordinator@1.0.0.js"></script>

<!-- אחריו — שאר הרכיבים לפי סדר הופעה (התחתון ראשון) -->
<script src="https://scriptable.dev/accessibility@1.0.0.js"></script>
<script data-token="TOKEN" src="https://fast-chat.up.railway.app/widget.js"></script>

API — לבוני רכיבים

אם אתם בונים ווידג'ט חדש ורוצים שיתמוך ב-coordinator, קוראים ל-register() פעם אחת בטעינת הסקריפט:

const pos = window.YBCoordinator
  ? window.YBCoordinator.register('my-widget', { side: 'left', size: 56 })
  : { bottom: 24, zIndex: 99999 }; // fallback כשcoordinator לא נטען

// לאחר יצירת האלמנט:
el.style.bottom = pos.bottom + 'px';
el.style.zIndex = pos.zIndex;
פרמטר ברירת מחדל תיאור
id — מזהה ייחודי לרכיב (מחרוזת)
side 'left' צד המסך: 'left' או 'right'
size 56 גובה הכפתור בפיקסלים
