כפתור WhatsApp

כפתור WhatsApp צף עם הודעה מוכנה מראש. שורת קוד אחת, RTL מלא, מתואם עם שאר הווידג'טים.

התקנה

<script src="https://scriptable.dev/whatsapp@1.0.0.js"
  data-phone="972501234567"
  data-message="שלום, אשמח לפרטים"></script>

מה הרכיב עושה

  • כפתור צף בצד ימין
  • הודעה מוכנה מראש בלחיצה
  • Tooltip עם שם העסק
  • תיאום מיקום אוטומטי עם Coordinator
  • פותח WhatsApp Web / אפליקציה
  • ללא backend — stateless לחלוטין

Attributes

Attribute חובה תיאור
data-phone ✓ מספר טלפון בינלאומי (ללא + וללא רווחים). דוגמה: 972501234567
data-message הודעה שתופיע מוכנה בשיחה. ברירת מחדל: ריק
data-label טקסט ה-tooltip. ברירת מחדל: שלחו לנו הודעה
data-target CSS selector לאלמנט שבתוכו יופיע הכפתור. ללא coordinator, ללא fixed position. דוגמה: #wa-container
