כפתורי שיתוף

שיתוף לרשתות חברתיות — צף עם תפריט, או מוטמע ישירות בדף. בחרו רשתות, סדר, כיוון פתיחה ופריסה.

דוגמאות שימוש

// צף, נפתח כלפי מעלה (ברירת מחדל)

<script src="https://scriptable.dev/share@1.0.0.js"
  data-networks="whatsapp,facebook,telegram,twitter,linkedin,copy"
  data-text="כתבה מעניינת"></script>

// צף, נפתח ימין לשמאל

<script src="https://scriptable.dev/share@1.0.0.js"
  data-networks="whatsapp,telegram,copy"
  data-direction="left"></script>

// מוטמע — אופקי

<div id="share-box"></div>
<script src="https://scriptable.dev/share@1.0.0.js"
  data-networks="whatsapp,facebook,telegram"
  data-target="#share-box"
  data-layout="horizontal"></script>

// מוטמע — אנכי

<div id="share-box"></div>
<script src="https://scriptable.dev/share@1.0.0.js"
  data-networks="whatsapp,telegram"
  data-target="#share-box"
  data-layout="vertical"></script>

Attributes

Attributeברירת מחדלתיאור
data-networkswhatsapp,facebook,telegram,twitterרשתות מופרדות בפסיק, לפי הסדר הרצוי
data-textכותרת הדףטקסט שיצורף לשיתוף
data-urlURL הנוכחיURL לשיתוף
data-directionupup / left — כיוון פתיחת התפריט הצף
data-target—CSS selector — מצב מוטמע (ללא floating, ללא coordinator)
data-layouthorizontalhorizontal / vertical — רק במצב מוטמע
