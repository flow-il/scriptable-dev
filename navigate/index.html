@1.0.0 ניווט ללא API key

כפתור ניווט

Google Maps ו-Waze בלחיצה אחת. פותח אפליקציה במובייל ודפדפן בדסקטופ — ללא API key, ללא הגדרות billing.

דוגמאות שימוש

// צף — שתי אפליקציות (popup בחירה)

<script src="https://scriptable.dev/navigate@1.0.0.js"
  data-address="רחוב הרצל 1, תל אביב"
  data-apps="google,waze"></script>

// צף — Waze בלבד (פתיחה ישירה)

<script src="https://scriptable.dev/navigate@1.0.0.js"
  data-address="רחוב הרצל 1, תל אביב"
  data-apps="waze"></script>

// מוטמע — כפתורים גלויים

<div id="nav-box"></div>
<script src="https://scriptable.dev/navigate@1.0.0.js"
  data-address="רחוב הרצל 1, תל אביב"
  data-apps="google,waze"
  data-target="#nav-box"></script>

// קואורדינטות מדויקות (מומלץ)

<script src="https://scriptable.dev/navigate@1.0.0.js"
  data-lat="32.0853"
  data-lng="34.7818"
  data-apps="google,waze"></script>

מה הרכיב עושה

  • פותח אפליקציה במובייל
  • פותח דפדפן בדסקטופ
  • אפליקציה אחת → פתיחה ישירה
  • שתי אפליקציות → popup בחירה
  • תמיכה בכתובת ובקואורדינטות
  • ללא API key

Attributes

Attributeחובהתיאור
data-addressאו data-lat/lngכתובת טקסט. דוגמה: רחוב הרצל 1, תל אביב
data-lat + data-lngאו data-addressקואורדינטות מדויקות — מומלץ למניעת שגיאות geocoding
data-appsאפליקציות מופרדות בפסיק לפי הסדר: google, waze. ברירת מחדל: google,waze
data-labelתווית ה-aria-label לכפתור הצף. ברירת מחדל: נווט אלינו
data-targetCSS selector — מצב מוטמע (כפתורים גלויים, ללא coordinator)
