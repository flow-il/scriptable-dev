@1.0.0 צ'אט WebSocket Telegram

וידג'ט צ'אט

צ'אט חי לאתר — גולש שולח הודעה, בעל העסק מקבל התראה בטלגרם ועונה מה-inbox. ללא WhatsApp, ללא תלות במטא.

התקנה

<script src="https://scriptable.dev/yellowbox@1.0.0.js"
        data-token="YOUR_TOKEN"
        async></script>

איך מקבלים token

  1. נרשמים בחינם ב-bizapp.yellowbox.co.il
  2. יוצרים עסק חדש — מקבלים Widget Token אוטומטית
  3. מחברים Telegram באופציה — כשגולש כותב, מגיע push עם קישור לתשובה
  4. מדביקים ב-data-token בקוד
