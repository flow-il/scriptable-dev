Versioning Policy

All URLs are permanently immutable. A pinned version will never change behavior. Safe to use in production.

Pattern Meaning Action needed
1.0.x Bug fix — identical behavior, safe to update Update freely
1.x.0 New feature — fully backward compatible Opt-in, test first
x.0.0 Breaking change — API or behavior changed Manual upgrade required
Every component renders a small version label in its UI so you can always identify which version is running on a specific site.
